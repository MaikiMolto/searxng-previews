SearXNG Previews

Thumbnail previews for SearXNG search results · Documentation

🚀 Quick Start

This extension needs a self-hosted Preview Service (backend) to generate thumbnails. It does not work on its own.

  • Install the backend via Docker: github.com/MaikiMolto/searxng-previews
  • Enter the backend URL and your SearXNG instance URL(s) below
  • Hit Save — done!

💡 Tip: Find your SearXNG URL

Open your SearXNG instance in a new tab, copy the address-bar URL (just the origin, e.g. https://search.example.com or http://192.0.2.10:8080) and paste it below. No trailing slash, no paths.

Important: http:// and https:// are different origins. If you access the same instance via both, list both URLs.

🔒 Using a Reverse Proxy (Zoraxy / nginx / Caddy / Traefik)?

If your SearXNG instance uses https://, the preview backend must also be served over HTTPS. Otherwise browsers will block the requests (Mixed Content).

The recommended setup is to put the preview service behind a reverse proxy with its own hostname (e.g. https://previews.example.com) and enter that URL above. Your proxy should forward to http://<internal-ip>:3200.

Two essentials:

  • CORS headers must pass through. The backend already sends Access-Control-Allow-Origin: *. Don't strip it in your proxy config.
  • Mixed-Content: If your SearXNG uses https://, the backend URL must also be https://.

Minimal nginx example:

location / {
    proxy_pass http://192.0.2.10:3200;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
}
